# Project agent memory

GitAway (repo name `travelos`, the product's former name). Design-first frontend on fake data; read `docs/brief.md` and `docs/plan.md` first.
Design language: the colour timeline on web and phone (design-system/DESIGN-SYSTEM.md "The colour timeline"; colour for kinds only, never days); phone motion Liquid, laptop motion a calm fade. Designs are drafted in Google Stitch, project 5068253051282871529 (design/DESIGN.md is its design system).

- Python via pixi only: `pixi run dev` (port 5002), `pixi run test`. Never pip. Page-JS browser tests (`tests_browser/`, headless Chromium, ~5s): `pixi run test-browser`, after a one-time `pixi run test-browser-install`. `pixi run test-random` runs the suite in random order (add `--randomly-seed=N` to repeat a run).
- `main.py` builds the FastHTML app and serves `/assets/…`; every screen is a module in `gitaway/pages/` exposing `register(app)`, appended to `SCREENS` in `gitaway/pages/__init__.py`. Placeholders register last as fallbacks, so a real screen on the same path wins; delete its entry from `placeholders.PLACEHOLDERS` when you ship it. Keep screens in their own modules so tickets can be built in parallel.
- `gitaway/layout.py` `page()` is the shared shell (fonts, tokens, header, footer, `data-theme` sunset|pacific). `gitaway/icons.py` `icon()` gives inline SVG icons; never use emoji.
- `gitaway/catalog.py` is the single fake catalog. Money is integer cents; display with `catalog.money()`.
- Motion (F-109, F-156): on the phone, tablet and installed app anything that opens (sheet, menu, popover, toast, card) grows out of what was tapped and folds back into it with `GA.motion.open/close/settle` (`assets/js/motion.js`); on a desktop (1020px up, not the installed app) `GA.motion.calm()` makes the same calls a short `--motion-desk` fade, no zoom, spring or outline-first, so callers never branch on width (`tests_browser/test_calm_desktop.py`); durations and easings are only the `--motion-*` tokens in `tokens.css`. `tests/test_motion_tokens.py` scans for literal times; `tests_browser/test_motion.py` samples the frames.
- Visual rules: `design-system/DESIGN-SYSTEM.md` (tokens in `assets/css/tokens.css`, shared components in `assets/css/base.css`). The artboard sources for each screen are in `docs/design/canvas/`.
- Photos in `assets/photos/` are CC0 area photos (see `CREDITS.md`), never presented as a hotel or room.
- Sign-in, families and storage are fh-saas (`gitaway/auth.py`, `docs/setup.md`). The process runs with the data folder (`GITAWAY_DATA_DIR`) as its working directory, so never use relative file paths; resolve from `Path(__file__)`. A family's trips, bookings, calendar, friends, rides, forks and saves live in its tenant database (`gitaway/familydb.py`, `docs/family-db.md`); the cookie holds only the sign-in. Tests sign in with the dev sign-in (`tests/test_signin.py` `sign_in`, `tid`; `person()` for model-level tests).
- Production (Railway, `Dockerfile`, `docs/setup.md`): `auth.production()` is true with `GITAWAY_ENV=production` or `RAILWAY_ENVIRONMENT`; it needs `GITAWAY_SECRET_KEY`, forces the dev sign-in off and the cookie https-only. `/healthz` skips every beforeware. Sign-in is a 30-day sliding cookie (`session.slide`); test pins and fixtures that need dev settings must not set `GITAWAY_ENV`.
- People join a family by invitation and have a role (admin, editor, viewer): `gitaway/members.py` (invites, memberships, active family), `gitaway/access.py` (the beforeware that gates every write by role), `docs/family-members.md`.
- One Ask box (`/trip/ask`, F-087): `gitaway/say.py` routes (a short request is a speak change, a long paste a convert plan), asks follow-ups and applies; `gitaway/pages/tab_ask.py` draws it. The old `/trip/add` Convert screens are gone (it redirects to the box). On a phone the centre Ask tab opens it as a sheet over the screen (F-104, `docs/trip-canvas.md`): the same routes answer fragments to `X-Ask: 1`, and `ask.js` is reused via `AskBox.init`.
- Family chat in the laptop panel (F-143, `docs/trip-canvas.md`): `gitaway/familychats.py` keys the chats (`trip`, plan, `plan:part`) and their per-person unread marks; `gitaway/pages/familydock.py` draws the pane over the Family tab's own bubbles and `thread.js` (no second chat); `/trip/family` hands a laptop on to `/trip/canvas?day=N&panel=family`.
- The old trip calendar is gone (F-147): `/calendar`, `/trips` and `/invite` only redirect (`gitaway/pages/calendar.py`; `docs/trip-canvas.md` "Retired: the old calendar" says where each thing went), and a test fails if any page or script links to `/calendar`. What the day pages share (lanes, free hour, note writer, ride href) is `gitaway/pages/dayshared.py`. Tests make a booking and plans with `tests/test_calendar.py` `book` and `add` (the add sheet's route `POST /trip/plans`, which runs an hour); tests_browser uses `helpers.seed_plan`.
- Sample data has one switch: `gitaway/showcase.py` (`showcase.on()` is false in production; `showcase.HIDDEN` lists the routes that then 404; `GITAWAY_SHOWCASE=1/0` overrides, never set it on Railway). New sample or community content must check `showcase.on()` and be tested in both modes (`tests/test_showcase.py`).
- Creator import (F-183): `/creators/import` turns a pasted blog, YouTube link, Instagram caption or text into a draft (`gitaway/importsource.py` reads it through the SSRF guard `gitaway/safefetch.py`; `gitaway/creatordraft.py` asks Claude Haiku 5.5 via `ai.py` job `creator-import`, validates, stores in community.db, publishes; `docs/ai-usage.md`, D-90..98). Never fetch a user's address except through `safefetch.fetch`.
- Creators, the rest (F-188 to F-192): the captain drafts a creator's post privately at `/admin/draft` and sends a `/claim/<token>` link (hashed, 30 days, single use; `pixi run draft-creators` drafts the A rows of `docs/research/creators.csv`); `/share-to-gitaway` is the installed app's share target; `/badge/plan-this-trip*.svg` is the blog button; `gitaway/stats.py` counts readers with no cookie (daily salted hash, no IP stored) for `/creators/stats`. Creator routes that exist before anyone publishes go in `showcase.REAL_ALWAYS`; blocking work in an `async def` route goes through `run_in_threadpool` (`tests/test_event_loop.py`).
- All my posts at once (F-190): `gitaway/blogscan.py` reads a blog's sitemap or feed (safefetch kind `xml`, defusedxml) and ranks its posts; `gitaway/draftjobs.py` is the job table and worker threads (`start()` at boot, tests call `run_pending()`); `gitaway/pages/creatordrafts.py` draws the scan, the picker and My drafts (`/creators/drafts`, the one list of every draft). A new fixed `/creators/<word>` route must also go in `community.RESERVED_HANDLES`.
- One top bar (F-139): `gitaway/topbar.py` `bar()` draws it for a signed-in person; `layout.site_header` and `phone.shell` include it and `assets/css/topbar.css` shows it only from 1020px up (the tablet keeps the old header, the phone its tabs). A new page document must include `topbar.bar()` unless it is the landing, sign-in or a full-screen tool (`/plan` booking, boarding passes). Tests that look for a trip's name or id on a page read `tests/pagebody.py` `without_bar(html)`, since the bar names the open trip.
- Test seams: HTTP routes through Starlette's TestClient (`tests/conftest.py` `client`) and the catalog's public functions.
- Partners (autopilot M2/M3): GitAway is a control plane; every /plan offer links `Book on <partner>` to `/go/<offer>` (`gitaway/pages/partners.py`, seam in `gitaway/partners/`: Aviasales for flights, Klook for stays and cars, Uber deep link; clicks in the family's `partner_clicks`). `TRAVELPAYOUTS_MARKER` makes `/go` a 302: flights to an Aviasales search with `marker=<marker>.<sub_id>`, stays and cars to a Klook link from the Travelpayouts partner-links API (`TRAVELPAYOUTS_TOKEN`, `_TRS`; 2s timeout, cached, else `KLOOK_FALLBACK_URL`; D-70); `pixi run probe-tp` makes one real call; without it (showcase on) it lands in the `/sandbox/...` stand-in checkout, whose POST records a simulated conversion and adds the booking to the trip as "Booked elsewhere · <partner>". `/partners` is the family's log. Off the showcase `/sandbox` is 404, `/go` needs the marker, `/partners` the token (`showcase._needs_keys`). Only `partners/travelpayouts._post` touches a network, at /go time; tests replace it. F-195 (D-145 to D-152): a trip may carry `home` (the reader's airport; none means the Aviasales link leaves the origin out and Aviasales asks) and `focus=disney` (only a creator's Disneyland trip: Anaheim stays, Disneyland tickets); Klook also sells `todo` (Tickets and things to do); `catalog.search_offer` + `/go/search-flight|stay|todo` are the honest, price-free offers, and off the showcase a reader from a creator's trip gets them as `pages/plan_search.py` instead of the sample workspace; a Klook link the API cannot make is a WARNING and a count on /admin (`partners/failures.py`).
